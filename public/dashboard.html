How many accounts run at the same time with "Start all". Each Chromium context uses ~350 MB RAM.

NETWORK

Each account can leave through its own IP address, which is what keeps Discord from rate limiting (429) the whole batch when several accounts run at once. Put one proxy per line in ip.txt next to server.js – account #1 uses proxy #1, account #2 uses proxy #2, and so on.

ACCEPTED FORMATS
host:port
host:port:user:pass
user:pass@host:port
http://user:pass@host:port
socks5://host:port

No scheme means HTTP. Chromium cannot authenticate to SOCKS proxies, so use HTTP proxies whenever a login is required. Lines starting with # are ignored.

WHERE TO GET PROXIES

Discord treats datacenter IP ranges with suspicion, so residential or mobile proxies work far better than cheap datacenter ones. Ask the vendor for sticky sessions – an IP that stays the same for 10+ minutes – because a proxy that rotates mid-quest breaks long PLAY_ON_DESKTOP runs.

  • Residential, sticky sessions – IPRoyal, Decodo (formerly Smartproxy), SOAX, Bright Data, Oxylabs, NetNut, Proxy-Cheap. Sold per GB; a quest run uses very little traffic, so the smallest plan usually covers a lot of accounts.
  • Cheap datacenter / ISP – Webshare (10 free proxies after signing up), ProxyScrape, Storm Proxies. Fine for testing that the wiring works, more likely to be flagged in day-to-day use.
  • Mobile (4G/5G) – the most trusted by Discord and the most expensive. Worth it only for accounts you care about.

Avoid free public proxy lists. Whoever runs the proxy sees your traffic, and these tokens are full account access – a free list is an easy way to lose every account at once.
